# Capacity this week

Use the shop's connected Cetec MCP. Do not invent hours, centers, or jobs. If scheduling or work center data is missing, say so and stop.

1. List work centers.
2. For the next five working days, load scheduled work or production load by center. Use only numbers the tool returned.
3. Call out centers that are over the capacity figure the tool returned. If the tool has no capacity figure, list the load and say you cannot call it over.
4. Name the jobs sitting on an overloaded center if the tool returns them.

Return: center, load, capacity if present, jobs if present. Do not move work or change a schedule. This skill is read-only.
