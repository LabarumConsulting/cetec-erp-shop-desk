# Customer desk

Use the shop's connected Cetec MCP. One customer per run. If the user did not name a customer, ask. Do not walk the whole order book.

1. Confirm the customer record the tool returned before you continue.
2. List open sales orders: order, part, qty, due date, status.
3. List open quotes: quote, part, age, value if present.
4. If an invoice tool returns a balance or open invoices for that customer, include past-due amount and the oldest invoice. If it does not, say AR was not returned.

Do not invent balances. Do not email the customer, create a quote, or take a payment. This skill is read-only.
