# Repeat NCR

Use the shop's own Cetec MCP. Do not invent NCR numbers. Do not close an NCR.

## When to use

- "What part keeps failing?"
- A quality trend, not the one-customer NCR list.

## Steps

1. List open NCRs and NCRs opened in the last 90 days.
2. Group by part. Keep parts with more than one.
3. Name the customers only if the tool returns them. Do not guess a customer from the part.
4. Do not close anything.

## Return

Part, NCR count, and the NCR numbers. If none repeat, say none.
