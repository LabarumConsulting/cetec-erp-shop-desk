# Buyer brief

Use the shop's connected Cetec MCP. Do not invent PO numbers, vendors, parts, or dates. If purchase orders are not available, say so and stop.

1. List open purchase orders. Keep lines that are past due or due within 7 days, using the dates the tool returned.
2. Name the vendor, part, quantity still open, and due date.
3. If a tool can tie the PO to a work order or sales order, include that order. If it cannot, do not guess the link.
4. Sort soonest due first.

Return a short list: PO, vendor, part, qty open, due date, blocking order if known.

Do not receive a PO, change a date, or email a vendor. This skill is read-only.
