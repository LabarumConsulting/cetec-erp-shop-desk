# NCR by customer

Use the shop's own Cetec MCP. Do not invent NCRs. Do not close one.

## When to use

- "What is open with {customer}?"
- Open nonconformances before a call.

## Steps

1. List open NCRs for that customer.
2. Name the part, the location, and days open if the tool returns them.
3. Do not close an NCR.

## Return

Customer, NCR, part, days open. If none are open, say so.
