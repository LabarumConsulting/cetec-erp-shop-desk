# Quotes ready to convert

Use the shop's own Cetec MCP. Do not invent quotes. Do not convert a quote. Converting is not an MCP write.

## When to use

- "Which quotes could we convert?"
- Sitting quotes where the part is on hand or the center has room.

## Steps

1. List open quotes with no recent activity. Name customer and part.
2. For the oldest few, check on hand and whether the likely work center is over this week. Cap this at five quotes so it does not walk the whole book.
3. Mark each as ready, blocked on material, blocked on capacity, or cannot tell.
4. Do not create an order.

## Return

Quote, customer, part, and the block if any. Say that convert is a person in Cetec, not this skill.
