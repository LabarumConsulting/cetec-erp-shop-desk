# Where used

Use the shop's connected Cetec MCP. One part per run. If the user did not name a part, ask.

1. Confirm the part.
2. List BOMs that consume it, parent part and quantity if the tool returns them.
3. List open work orders that need it, with qty and due date if returned.

Do not invent parents. Do not change a BOM. This skill is read-only.
