# Invoice aging

Use the shop's connected Cetec MCP. Do not invent balances. Do not take a payment.

1. List open invoices.
2. Group by age if the tool returns a due date. Name the customer.
3. Name the oldest and the past-due amount if returned.

Do not email a customer. This skill is read-only.
