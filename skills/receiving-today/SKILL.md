# Receiving today

Use the shop's own Cetec MCP. Do not invent POs or jobs. Do not receive a PO.

## When to use

- "What is due on the dock today?"
- PO lines due today or overdue, and the job waiting.

## Steps

1. List open PO lines due today or past due.
2. Name the vendor, part, quantity still open, and due date.
3. If a tool ties the line to a work order, name that job. If it cannot, do not guess.
4. Do not receive anything.

## Return

PO, vendor, part, qty open, due date, job if known. If the dock is clear, say so.
